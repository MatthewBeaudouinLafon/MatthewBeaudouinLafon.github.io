Belidor: A Language for User Interface Analogies

A specification language for the structure underlying user interfaces. Beldior’s semantics can express a wide range of UIs and surface analogies between very different interfaces (eg. a calendar and a video editor).

CHI 2026 · Matthew T. Beaudouin-Lafon, Devamardeep Hayatpur, Arvind Satyanarayan, Haijun Xia

Color Field: Professional Vision for Color Grading

An interactive tool to visualize the effect of color filters as a vector field over a color space. We draw inspiration from Goodwin’s Professional Vision to help novices “see” color grading like experts.

UIST 2023 · Matthew T. Beaudouin-Lafon, Jane L. E, Haijun Xia

Mason View

A content-driven viewport management system where users can detach elements from webpages and compose them into UI mashups.

UIST 2023 Demo · Bryan Min, Matthew T. Beaudouin-Lafon, Sangho Suh, Haijun Xia

MathMap

Design of an interactive tool that helps students do algebra without doing it for them. Users navigate towards solutions by choosing algebraic transformations.

UIST 2021 Poster · Matthew T. Beaudouin-Lafon, Haijun Xia
